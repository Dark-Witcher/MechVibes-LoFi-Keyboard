# MechVibes LoFi Sounds

A custom LoFi keyboard sound pack for [MechVibes](https://github.com/Mechvibes/Mechvibes).

## Contents

- `config.json` — MechVibes sound pack configuration
- `keyboard1.mp3` — primary key sound
- `keyboard2.mp3` — alternate key sound
- `keyboard3.mp3` — alternate key sound
- `keyboard4.mp3` — alternate key sound

## Installation

Copy the sound pack directory into the MechVibes custom sound directory and select **LoFi Sounds** from the available sound packs.
